# Monster Contest Bot для Telegram

> Секретный `.env` не хранится в репозитории. При первом запуске `main.py` сам
> попросит токен и создаст настройки только на вашем компьютере.

Бот проводит две игры: **Казино 777** и **Перебив**. Администратор полностью
управляет ими в личных сообщениях через inline-кнопки. Стартовые и финальные
посты публикуются в выбранном канале, а игровые сообщения отслеживаются в
выбранной группе.

## Что реализовано

- доступ к личной панели только после команды-промокода `/MonsterLydka1488`;
- выбор группы и канала прямо в боте;
- сохранение доступа и выбранных чатов в `monster_bot.sqlite3`;
- **Казино 777**: приз, нужное количество выпадений 777 одному игроку и
  необязательный скриншот;
- участники сами отправляют нативный Telegram-слот 🎰 в группе или комментариях
  под постом;
- **Перебив**: приз, длительность удержания, отображаемая стоимость сообщения в
  звёздах и необязательный скриншот;
- уведомление о каждом новом лидере и автоматическое завершение таймера;
- публикация победителя и обращения к `@Monster_Tags`;
- указанные premium emoji ID с автоматическим переходом на обычные emoji, если
  Telegram не разрешит боту использовать конкретный custom emoji;
- жирный и курсивный текст в игровых публикациях;
- единый запуск двойным щелчком по `main.py`.

## Подготовка Telegram

1. В @BotFather откройте `/setprivacy`, выберите бота и нажмите **Disable**.
   Иначе бот не увидит обычные сообщения и слоты участников.
2. Добавьте бота в группу, где будут проходить игры, и назначьте его
   администратором. Так Telegram гарантированно передаст боту обычные сообщения
   и нативные слоты 🎰.
3. Добавьте бота в канал администратором и разрешите публикацию сообщений.
4. Убедитесь, что пользователь, который управляет ботом, является
   администратором и группы, и канала.
5. В настройках канала привяжите выбранную группу как **Обсуждение**. Бот перед
   стартом проверит, что в панели выбрана именно эта группа; при несовпадении
   игра не запустится и покажет понятную ошибку.
6. После добавления бота отправьте любое сообщение в группу. Для канала можно
   опубликовать тестовый пост или пере-добавить бота: так чат появится в списке
   выбора.

Telegram Bot API не предоставляет боту общий список всех чатов аккаунта.
Поэтому в панели показываются только группы и каналы, о которых бот уже получил
событие после добавления.

## Запуск через Python в Windows

Нужен Python 3.11 или новее.

1. Распакуйте архив.
2. Откройте папку `monster_contest_bot`.
3. Дважды щёлкните `main.py`.

Или выполните:

```bat
py main.py
```

При первом запуске `main.py` скрыто запросит новый токен из @BotFather, создаст
локальный `.env`, создаст `.venv`, установит `aiogram==3.30.0` и запустит бота.
Никакие BAT-файлы или ручные команды установки не нужны. Окно должно оставаться
открытым. При следующих запусках настройка и установка не повторяются.

Пакет `python-dotenv` не нужен: `.env` читается встроенным загрузчиком.

## Запуск на хостинге

Файл `.env` загружать в GitHub не требуется. В настройках хостинга откройте
раздел **Environment Variables** или **Secrets** и добавьте:

```text
BOT_TOKEN=новый_токен_из_BotFather
```

Команда запуска:

```text
python main.py
```

При наличии переменной `BOT_TOKEN` файл `main.py` не запрашивает ввод, не требует
локальный `.env` и запускается в среде хостинга. Остальные параметры имеют
безопасные значения по умолчанию и при необходимости также задаются через
Environment Variables.

## Первый запуск и панель

1. Откройте личные сообщения с ботом.
2. Отправьте `/MonsterLydka1488`.
3. Нажмите **Открыть панель**.
4. Нажмите **Выбрать чат**, затем **Выбрать канал**.
5. Выберите **777** или **Перебив** и ответьте на вопросы настройки.

Все управляющие действия выполняются только в личном диалоге. Участники в
группе лишь отправляют слоты или сообщения игры.

## Как работает Казино 777

Администратор задаёт приз и количество необходимых комбинаций 777. Счётчик
ведётся отдельно для каждого игрока. Например, если указано `3`, победит первый
участник, который сам выбьет 777 три раза. Результат Telegram-слота считается
честным серверным значением; бот не подменяет выпадение.

Для отправки слота участник выбирает emoji 🎰 в Telegram и отправляет его как
анимированный dice. Обычная картинка, стикер или текст `777` не засчитываются.
Каждый нативный слот обрабатывается без cooldown: выигрышная комбинация не будет
пропущена, даже если игрок отправил её сразу после предыдущей попытки. При 777
бот немедленно отвечает под сообщением, что результат засчитан.

## Как работает Перебив

Первое сообщение назначает лидера и запускает таймер. Сообщение другого
участника перебивает лидера и запускает полный выбранный интервал заново.
Собственные сообщения лидера не продлевают время. Когда интервал истекает, бот
публикует победителя в канале.

Поле «стоимость сообщения в звёздах» отображается в анонсе. Бот не списывает
Telegram Stars автоматически: реальное списание требует отдельного платёжного
сценария с подтверждением каждого платежа.

## Настройки `.env`

Этот файл создаётся автоматически файлом `main.py`; вручную настраивать его не
нужно. Он добавлен в `.gitignore` и не должен попадать в GitHub.

| Переменная | По умолчанию | Описание |
|---|---:|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `OWNER_IDS` | пусто | сохранено для совместимости |
| `ACCESS_CODE` | `/MonsterLydka1488` | промокод личной панели |
| `DATA_FILE` | `monster_bot.sqlite3` | локальная база доступа и чатов |
| `INTERCEPT_SECONDS` | `120` | значение совместимости |
| `CASINO_COOLDOWN_SECONDS` | `3` | параметр совместимости; нативные слоты не пропускаются |
| `PRIZE_CALL` | `@Monster_Tags, выдай приз победителю!` | финальная фраза |

## Проверка

Игровой движок тестируется без подключения к Telegram:

```bash
python -m unittest discover -s tests -v
```

Активные игры хранятся в памяти процесса. После перезапуска текущую игру нужно
начать заново. Доступ, известные чаты и выбор администратора сохраняются в базе.
Запускайте только один экземпляр бота с данным токеном.

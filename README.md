# Monster — бот розыгрышей для Telegram

Готовый бот с личной панелью на инлайн-кнопках. Организатор выбирает канал и
настраивает игру только в личных сообщениях боту. Старт и завершение публикуются
в канале, а игровые сообщения участников учитываются в комментариях под постом.

> Секретный `.env` не хранится в репозитории. При первом запуске `START_BOT.py`
> сам попросит токен и создаст этот файл только на вашем компьютере.

## Что умеет бот

- **Казино 777** — организатор задаёт приз и количество комбинаций 777, которое
  должен выбить один участник. Люди сами отправляют анимированные слоты 🎰 в
  комментариях. Бот учитывает только настоящий Telegram-слот со значением 777.
- **Перебив** — организатор задаёт приз, время удержания и отображаемую стоимость
  текстового сообщения. Первый игрок становится лидером; сообщение другого
  игрока перебивает его и запускает таймер заново. Собственные сообщения лидера
  таймер не продлевают.
- **Угадай число** — организатор тайно задаёт число от 1 до 100. Первый точный
  ответ в комментариях побеждает.
- Для каждой игры можно по желанию прикрепить фотографию к стартовому посту.
- Игры и таймеры сохраняются в `data/bot.sqlite3`, поэтому «Перебив» продолжится
  после обычного перезапуска бота.
- В постах используются заданные premium/custom emoji. Если Telegram не разрешит
  этому боту отправить custom emoji, бот автоматически опубликует обычные emoji.

После победы бот публикует в канале приз, победителя и строку:

```text
@Monster_Tags, выдай приз победителю!
```

## Подготовка Telegram

1. В настройках канала привяжите группу обсуждений: **Управление каналом →
   Обсуждение**. Именно в ней находятся комментарии к постам.
2. Сначала запустите бота, затем добавьте его **администратором** в канал с
   правом публикации сообщений.
3. Добавьте этого же бота **администратором** в связанную группу обсуждений.
4. В `@BotFather` откройте `/setprivacy`, выберите бота и нажмите **Disable**,
   чтобы бот гарантированно видел обычные текстовые сообщения участников.
5. Откройте личный чат с ботом и отправьте:

```text
/MonsterLydka1488
```

Если бот был добавлен в канал до запуска и канал не появился в списке, измените
права бота в канале и сохраните их либо удалите и добавьте бота снова. После
этого нажмите **«Обновить»** в выборе канала.

## Запуск одним Python-файлом в Windows

Нужен Python 3.11 или новее.

1. Распакуйте архив.
2. Откройте папку `monster_contest_bot`.
3. Запустите `START_BOT.py` двойным щелчком.

Или откройте командную строку в этой папке и выполните:

```bat
py START_BOT.py
```

При первом запуске `START_BOT.py` попросит вставить новый токен из `@BotFather`,
создаст локальный `.env`, затем сам создаст `.venv`, установит `aiogram` и
запустит бота. Введённый токен на экране не отображается. Пакет `python-dotenv`
не используется, поэтому прежняя ошибка его установки больше не возникнет.
Окно необходимо оставлять открытым, пока бот работает.

## Как запустить игру

1. В личном чате активируйте промокод и нажмите `/start`.
2. Выберите **Казино 777**, **Перебив** или **Угадай число**.
3. Выберите канал инлайн-кнопкой.
4. Заполните настройки, отправьте фотографию или выберите **«Без скриншота»**.
5. Проверьте итог и нажмите **«Опубликовать»**.

Участники играют только в комментариях под опубликованным постом. Кнопка
**«Активные»** в личной панели позволяет остановить свою игру.

## Важно про Telegram Stars

Указанная цена сообщения в «Перебиве» выводится в посте как условие конкурса.
Telegram не позволяет автоматически списывать Stars за обычный текст в чате.
Для настоящей оплаты нужна отдельная схема с инвойсом и платёжной кнопкой.

## Ручной запуск и тесты

Если автоматический запуск не нужен, сначала скопируйте `.env.example` в `.env`
и замените `BOT_TOKEN` внутри. Затем выполните:

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app
```

Проверка логики без подключения к Telegram:

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Docker

```bash
docker compose up -d --build
docker compose logs -f
```

Остановка:

```bash
docker compose down
```

## Настройки `.env`

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен Telegram-бота |
| `ACCESS_CODE` | код доступа без начального `/` |
| `OWNER_IDS` | необязательные Telegram ID владельцев через запятую |
| `DATABASE_PATH` | путь к SQLite-базе |

Не запускайте одновременно две копии бота с одним токеном: Telegram будет
останавливать один из процессов из-за конфликта long polling.
